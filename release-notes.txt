Version 1.6.8

• Replaces the simulated in-content toolbar with a real native macOS NSToolbar integrated into the window title bar.
• Right-click anywhere in the native toolbar to use the standard macOS Icon and Text, Icon Only, Text Only, and Customize Toolbar… menu.
• Uses Apple’s built-in Customize Toolbar palette so buttons, Space, Flexible Space, and the default set can be dragged directly into and out of the toolbar.
• Native toolbar customizations are automatically saved and restored by macOS.
• Preserves Paste/Open, the standalone wide Retrieve action, CSV/Transcript, Threads/Messages, Settings, and the user’s existing toolbar layout as the starting configuration.
• Removes the separate custom toolbar editor because the system toolbar now provides the same interaction as Apple Mail and other Mac apps.
