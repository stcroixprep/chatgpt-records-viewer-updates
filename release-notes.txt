Version 1.6.13

• Compresses the conversation list when a chat preview opens instead of allowing the list to slide horizontally underneath the preview.
• Replaces the Threads table with a vertical-only conversation list whose columns resize to the available width, eliminating horizontal scrolling in the conversation list.
• Keeps the chat preview fixed on the right and restores the full-width conversation list when the preview is closed.
• Makes long ChatGPT responses easier to read by preserving Markdown structure and visually splitting dense single-paragraph answers into shorter paragraphs without changing the underlying message text.
• Fixes attachment downloads to follow the Compliance API's documented 307 file redirects as clean signed-URL requests rather than forwarding the Admin API authentication request through the redirect.
• Falls back from expired or missing temporary chat-file references to matching active Library files when available.
• Shows the actual attachment retrieval error in the preview when a file still cannot be downloaded, making permission or retention problems visible instead of hiding them behind a generic message.
