Version 1.4.0

• Requires Touch ID or the Mac login password every time Records Viewer launches.
• Stores the OpenAI Admin key in macOS Keychain with user-presence protection.
• Keeps the Admin key only in memory during an unlocked session.
• Adds Lock Records Viewer and clears loaded records/attachments when locked.
• Auto-locks after inactivity (15 minutes by default) and when the Mac session locks or sleeps.
• Locks the Settings window until Records Viewer is authenticated.
• Keeps Sparkle updates user-approved and adds a separate manual GitHub release-approval workflow.
