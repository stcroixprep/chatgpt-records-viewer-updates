Version 1.6.19

• Introduces St. Croix Preparatory Academy Developer ID signing and Apple notarization for standard macOS installation and in-place Sparkle updates.
• Adds a default Readable View for ChatGPT conversation transcripts. Known presentation tags are converted to readable text instead of showing formatting markup; Show Raw Content preserves access to the original, unmodified message.
• Lets you search for multiple staff email addresses using removable blue recipient tokens, with matching records from any selected user.
• Adds ascending and descending sorting for the Last activity, User, Conversation, and Messages columns.
• Simplifies conversation metadata and matching-message counts into plain, non-clickable labels rather than button-like bubbles.
• Improves toolbar appearance, search-field spacing and contrast, and simplifies the Retrieve dialog header.
• Downloads up to four independent Compliance log files concurrently, with bounded retries for temporary service throttling and more accurate progress reporting.
• Improves read-only fallback and diagnostic messages for uploaded attachments. Attachment availability and permissions remain subject to the OpenAI Compliance API.
• Keeps the empty Conversations screen hidden until retrieval or import, and preserves the existing Touch ID and Keychain security experience.

Release notes cover the changes since the last published Sparkle version, 1.6.17.
