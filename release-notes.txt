Version 1.6.21

• Renames the macOS app ChatView to represent both ChatGPT and Claude staff records.
• Replaces the old app artwork with a platform-neutral ChatView icon featuring overlapping conversation bubbles and a search lens.
• Keeps the bundle identifier, executable, Keychain service, Sparkle feed URL, and public update archive filename unchanged for continuity with installed versions.
• Adds Claude Enterprise Compliance API retrieval alongside ChatGPT Enterprise/Edu retrieval, including staff filters, date and message search, conversation transcripts, and available attachments.
• Uses separately secured provider access keys in macOS Keychain with the existing authentication and automatic lock behavior.
• Displays Claude's name and icon in Claude transcripts and the correct provider label in the Messages table.

These release notes cover changes since the previously published Sparkle version 1.6.19. The app does not provide automatic long-term archival or legal holds.
