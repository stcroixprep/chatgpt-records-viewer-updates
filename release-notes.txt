Version 1.6.15

• Hides the app name from the main window title bar, while preserving its macOS menu bar and accessibility identity.
• Makes the macOS title bar transparent with a full-size content view, uses the system window background, and removes the toolbar divider for a unified Mail/Safari-style appearance.
• Preserves the existing native toolbar controls and user-saved toolbar configuration.
• Avoids resetting the toolbar or validating items while the customization palette is actively handling drag-and-drop.
• Adds a Toolbar menu with Customize Toolbar…, Add Flexible Space, and Add Space as reliable ways to adjust toolbar spacing even if drag-and-drop is unavailable on a particular macOS version.
• Keeps Touch ID authentication, local Keychain credentials, the same app bundle identifier, and the existing signed Sparkle update feed.
