Version 1.6.0

• Increases overall contrast so settings cards, chat content, tables, and transcript areas remain clearly legible over desktop content.
• Uses Apple's current SwiftUI Liquid Glass APIs for interactive controls, including glassEffect, interactive glass, and native glass button styles when available.
• Builds with the Xcode 27 GitHub runner so macOS 27 can use the newest Liquid Glass behavior.
• Keeps content surfaces more solid while reserving Liquid Glass for controls and navigation, matching Apple's current design guidance.
• Removes the “Local” pill and the lock button from the main toolbar.
• Keeps locking available from Settings and preserves Touch ID / Mac password authentication, Keychain storage, auto-lock, Sparkle signing, and user-approved updates.
