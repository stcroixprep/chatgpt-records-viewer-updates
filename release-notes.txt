Version 1.6.1

• Fixes the double-authentication experience when opening Records Viewer.
• New Admin-key storage uses Keychain access control with userPresence and reuses the same LocalAuthentication context that already satisfied Touch ID or the Mac login password.
• Existing installs automatically migrate the legacy Keychain item the first time 1.6.1 unlocks it. Because the old item used macOS's legacy app-access ACL, that migration may require the login Keychain password one final time; subsequent launches should use only the normal Touch ID / Mac authentication flow.
• Fixes the Staff email filter so the user-selection chevron is an inline trailing control and stays vertically aligned inside the field.
• Keeps all v1.6.0 Liquid Glass, contrast, security, auto-lock, Sparkle signing, and update behavior.
