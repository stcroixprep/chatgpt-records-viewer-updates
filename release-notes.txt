Version 1.5.1

• Redesigns the Retrieve window with Google Vault-style search criteria.
• Adds a staff-user field with a selectable list of users already loaded in the current session, plus direct email entry.
• Adds message search terms, conversation-title filtering, speaker selection, and From/Through date criteria before retrieval.
• Preset date buttons for Today, Last 24 Hours, and Last 7 Days remain available.
• Retrieval still uses OpenAI's time-based Compliance log feed; user/text/title/speaker criteria are applied locally immediately after download.
• Search criteria carry into the main viewer so the returned result set is already filtered when the Retrieve window closes.
